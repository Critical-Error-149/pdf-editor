Quellcode
---------

PDF Editor: vollständig im Ordner „Quellcode“ (einschließlich build.py, mit dem diese .exe gebaut
wurde, und tools/). Bauen: Python 3.14 installieren, dann im Ordner „Quellcode“
  python -m pip install -r requirements.txt pyinstaller
  python build.py

Unveränderte Bibliotheken – Quellcode genau dieser Versionen:
  PyMuPDF 1.28.2 (enthält MuPDF 1.28.2):
    https://pypi.org/project/PyMuPDF/1.28.2/#files  (Quellarchiv PyMuPDF-1.28.2.tar.gz)
    https://github.com/pymupdf/PyMuPDF  und  https://mupdf.com/releases
  Qt 6.11.2:        https://download.qt.io/official_releases/qt/6.11/6.11.2/single/
  PySide6 6.11.2:   https://download.qt.io/official_releases/QtForPython/pyside6/
                    https://code.qt.io/cgit/pyside/pyside-setup.git (Version v6.11.2)
  FFmpeg 7.1.5:     https://ffmpeg.org/releases/ffmpeg-7.1.5.tar.xz
  Python 3.14.0:    https://www.python.org/downloads/source/
  PyInstaller 6.22.3: https://pypi.org/project/pyinstaller/6.22.3/#files

Austauschen der LGPL-Bibliotheken: Qt, PySide6 und FFmpeg liegen als einzelne Dateien im Ordner
„_internal“ (z. B. _internal\PySide6\Qt6Core.dll, avcodec-61.dll). Du darfst sie durch eigene,
kompatible (auch selbst gebaute oder veränderte) Fassungen ersetzen.
